# 慢慢来 · 今晚早一点

中文、移动端优先的晚间家务安排工具。无后端，无账号，无外部字体或 API。真实数据只保存在当前浏览器的 localStorage 中，首次没有示例记录。

## 开发与验证

需要 Node.js 20+（本环境为24）。

```sh
npm ci --cache /tmp/quiet-evening-npm-cache
npm test
npm run build
npm run dev
```

`npm run build` 同时生成根目录 `index.html`，内嵌样式和应用逻辑，可供单文件查看器预览，也可下载到本机浏览器打开。完整 PWA 安装和离线缓存仍需完整站点与 HTTPS。

默认监听所有网卡的5173端口。`PORT` 可修改端口。生产静态文件在 `dist/`，也可直接用任意静态服务器托管。必须通过HTTPS部署才能在iPhone上安装、使用离线缓存；本地回环地址仅用于开发测试。

浏览器验证：先启动开发服务，再运行 `npm run test:browser`。默认使用 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定其他 Chromium。测试创建隔离浏览器上下文，不写入日常使用的数据。截图输出到忽略的 `test-results/`。

## 使用

- 今晚自动加入喂猫、洗澡、咖啡、刷牙、准备明天衣服五项；铲屎等按需添加。洗头整套任务会替换尚未开始的普通洗澡。
- 推荐卡启动前可覆盖预估。第一步到收尾整套计时；暂停、关闭和锁屏后按时间戳恢复。
- 默认依赖优先、必做优先、较短优先；上移任务后尊重手动顺序，洗衣依赖仍有效。
- 洗衣准备完成后确认实际启动时间与机器时长；晾衣需等待机器完成，也可标记已经洗好。等待不计入主动耗时。
- 23:30为收工目标，00:00放下手机。凌晨04:00划分晚间；跨零点不会把目标滚动到明晚，正在进行的计时保持原晚间。
- 洞察中的补记和编辑支持起止时间、备注、排除异常、删除。最近最多10条有效记录用于中位数与最短至最长范围，少于3条标记样本较少。
- 设置可调整模板、默认属性、目标与缓冲；模板修改不追溯历史。JSON备份可完整恢复，恢复前校验并二次确认。CSV用于查看记录。
- 备份包含个人数据，请自行妥善保存。恢复会完整替换本机数据；清理浏览器数据会丢失本地记录。

## 当前验证及限制

单元测试覆盖默认任务、凌晨归属、超时目标、并行洗衣、暂停计时、备份校验、记录时间和排除统计。浏览器脚本覆盖开始/暂停/刷新/完成、编辑、异常排除、备份往返与坏文件拒绝、多标签状态同步、离线重开与运行计时恢复、390px与桌面布局。

未验证iPhone真机/Safari；Chromium仿真不代表iOS真机验证。无锁屏通知、后台闹钟、云同步或账号。离线功能需首次完整加载成功；外部托管认证可能影响离线冷启动。用户已在Netlify部署；本环境未核验当前线上版本，旧交接文档的站点地址不代表当前部署地址。

localStorage不可用/配额不足时会显式提示；加载损坏数据时停止自动保存以保护原数据，可用有效JSON备份恢复。多标签用版本校验和storage事件降低冲突，但localStorage不提供跨进程事务，极短同时写入仍存在竞争窗口，建议单标签计时。

## 新增的晚间安排与洞察

- 首页“最晚几点开始”：分别倒推只做必做、全部已选任务的最晚开始时间。复用依赖排程，洗衣与家务并行，并扣除设置缓冲。超过该时间会如实显示已过多久；计时进行中隐藏该卡，改看当前收工估算。
- 开始前分开展示“通常需要多久”（最近最多10次有效记录的中位数和最短至最长范围）与“你这次预计多久”。无历史则明确标记初始参考；本次输入独立保存为预估。
- 预估准确度按稳定任务ID分组：每类最近最多10条有效记录的平均绝对误差；至少6条同类记录才分前后两组比较，不作心理原因或统计显著性推断。
- 今晚进度/结束小结展示主动记录合计、第一件开始到最后一件结束的跨度、预估合计和实际收工时间。空档通过主动时段并集计算，包含暂停、等待和休息但不区分原因；已排除洞察的记录仍计入事实小结并标注。
- 额外验证：`node tests/evening-features.mjs`、`node tests/target.mjs`、`node tests/standalone.mjs`，均针对构建后的单文件入口，无需运行服务器。

任务添加回归：`npm run test:add-task`。覆盖390px/桌面下常用与自定义任务添加、刷新保留、弹窗内错误反馈、重复任务过滤、多标签重复拦截、洗头替换、计时中添加以及存储失败回滚。

## 受限文件预览兼容（v1.1.2）

部分HTML查看器使用没有同源权限、甚至不允许原生表单提交的沙箱。应用现在直接处理表单按钮交互并执行字段校验；本机存储被浏览器明确拒绝时进入临时预览，顶部持续显示“未保存到本机”。临时模式的任务、计时、编辑、洞察均可交互，但刷新/关闭会丢失；不能用它替代正式浏览器中的持久保存。已有损坏数据和配额不足仍显式报错，不自动覆盖或清空。

`npm run test:preview` 实测 `sandbox="allow-scripts"` 和 `sandbox="allow-scripts allow-forms"` 两种受限iframe，验证添加的常用/自定义任务确实出现在今晚列表中，以及修改目标、设置、完成计时和刷新后临时数据丢失的提示。普通浏览器下的持久化测试独立保留。构建生成独立版本文件 `quiet-evening-v1.1.2.html`，用于重新打开新版本。

## 晚间组合与结束小结（v1.2.0）

首页提供普通夜、洗头夜、洗衣夜、洗头＋洗衣四种一键组合，仅应用于今晚。洗头替换未开始的普通洗澡；洗衣组合加入准备与晾衣，依赖排程让机器等待与其他事情重叠。反复点击不重复添加，不覆盖本次预估。切换时保留完成记录、活动计时、已启动的洗衣与手动添加的额外任务；仅移除之前组合加入且尚未开始的多余任务。若洗澡已经完成或正在做，保留原任务并说明，不再重复加入另一套洗澡。

“查看今晚小结”支持空状态、部分完成和全部完成；最后一项完成时自动定位到结束小结。小结展示主动合计、跨度、空档、预估与实际、逐项记录和实际收工时间。新计划保存当晚目标快照，后续调整默认目标不会更改历史对比；旧计划没有快照时标记按当前目标参考。小结由原始记录计算，不额外生成重复统计记录。

运行 `npm run test:combos` 验证普通浏览器与禁止本机存储、原生表单的iframe中的组合和小结交互。当前独立预览为 `quiet-evening-v1.2.0.html`。

## 完成备注与差异线索（v1.3.0）

每次点击完成先立即结束计时并保存完成记录，然后显示可跳过的备注。默认八种情境可多选：突发事件/被打断、顺手做了别的事、准备或收尾更多、步骤或份量增加、设备或用品耽误、中途休息、步骤或份量较少、预估不确定；另有500字自由备注。备注填写不增加任务实际耗时；勾选被打断不自动扣时间或排除洞察。可独立勾选“这次明显异常，不纳入洞察”。关闭或跳过备注也不会丢失已完成记录。

已完成任务的“备注”按钮可随时补改，历史编辑/补记共用同一组情境选项。原始记录与晚间小结展示备注，JSON备份完整保留、CSV增加情境与自由备注列。旧备份未填原因仍可恢复。

同类任务最近最多10条有效记录按情境分别统计数量与“实际−预估”的中位差，少于3次标记样本较少。多选可能被多个情境重复计数，未备注不代表无事件；只描述观察到的关联，不自动推断因果。编辑、删除或排除后重新计算。

`npm run test:notes` 验证普通/受限预览中的多选、自由备注、完成先落盘、备注不计时、补改与清除、统计与排除，以及普通浏览器的JSON恢复和CSV导出。新入口为 `quiet-evening-v1.3.0.html`。

## 到家模式与独立刷牙（v1.4.0）

新晚间默认先显示到家模式，完整安排折叠在下方。固定第一步默认为喂猫，设置中可调整优先任务；若已完成、未加入今晚或依赖未满足，则选择其他可开始的任务。按钮直接启动真实任务，采用近期中位数参考（保留本次手动覆盖），无须再填写预估；从准备到收尾计时，需要休息可暂停。可选择直接看完整安排。

休息支持5分钟、10分钟或暂时不定；使用结束时间戳恢复，允许延长。到点只在页面可见且进入今晚时邀请一次，无后台或锁屏推送保证。微动作引导为坐直、双脚落地、愿意时站起来，不要求打勾，不计时，不产生完成记录。仅保存模式与休息恢复所需状态，未加入“开始前等待”统计。

洗澡与刷牙分开：默认喂猫6分钟、洗澡15分钟、咖啡12分钟、刷牙3分钟均为可编辑初始参考。刷牙要等全部其他已选任务完成，包括晾衣；即使手动上移也不能提前开始。洗头组合仍单独安排刷牙。

首次读取旧数据时，旧“洗澡及洗漱”模板及其历史归入保留类别，新洗澡独立积累参考；只替换当前晚间尚未开始的旧任务并补入刷牙，不更改过去晚间的任务清单或原记录内容。正在计时的旧任务保持原实例与计时。旧版备份可以恢复并迁移。

`npm run test:arrival` 验证到家模式、休息刷新恢复、再次休息、微动作、直接计时、暂停、优先任务设置和最后刷牙；普通与受限预览均覆盖。预览入口 `quiet-evening-v1.4.0.html`。

## 主屏幕更新与收工曲线（v1.7.0）

联网打开或回到应用时检查版本（`version.json`）；设置提供手动检查与更新按钮。新Service Worker安装后等待用户确认，通过消息激活，控制器切换后才刷新；不主动中断输入。确认前先写入当前业务状态，原始记录、计时和休息时间戳不清理。发现更新可稍后处理。`netlify.toml` 指定构建并发布 `dist/`。Netlify `_headers` 为入口、worker和版本文件设置重新验证/不缓存策略；版本文件不使用离线缓存冒充最新。首次从缺少更新机制的旧版本升级，可能仍需关闭旧主屏幕窗口及同站Safari页后联网重开。没有iPhone真机验证，也不能保证快捷指令“打开URL”直接唤起独立PWA窗口。

点击「我到家了」保存当前时间，再进入休息或第一件小事；重复点击不覆盖，可以手动修正或清空。到家时间独立保存，不从任务记录推测。新计划无历史记录时先显示记录到家的入口，仍可直接展开完整安排。

今晚提供到家至收工时间轴、整晚跨度、实际家务用时与其余时间。家务按非暂停时段的并集合计，重叠补记不重复计算；其余时间不自动解释为拖延。未收工只显示已有家务记录。洞察提供最近7/14/30个日历日的到家与收工钟点图，以及日期对齐的家务分钟柱图。跨零点连续显示，缺失日期不补值、不跨缺失日期连接收工曲线。收工只取全部已选任务完成且每项有记录的晚间；旧记录保留收工时间但到家点为空。虚线为当前目标参考。

点击圆点、家务柱子（支持键盘）或日期行，查看时间轴与各项家务，补记到家时间、工作/加班、兴趣/学习、休息/娱乐、运动、家人/社交、其他活动及自由备注。“没有额外活动”与其他选项互斥，未填不等于没有。备注和到家时间跟随完整备份，不改变任务计时或自动认定收工早晚的原因，也不分配活动时长。收工时间通过修改原始任务记录修正，编辑/删除后重新计算。

`npm run test:updates` 使用真实本地HTTP服务模拟新旧worker/版本切换，验证不强制刷新、取消时保留输入、确认后更新、计时/休息不丢失以及新版离线重开。`npm run test:finish-chart` 验证普通/受限预览的曲线范围、圆点与键盘、活动备注保存/再打开/互斥以及删除记录后重算。

## 洗衣等待与任务推荐修复（v1.7.3）

当前任务推荐独立依据现在可执行的任务，不因晾衣缺少机器结束时间而阻塞其他家务。排程保留缺失依赖之前可执行的部分，完整预计结束时间仍标记为待确定。洗衣进行中先推荐其他可做的事；洗好后在下一个任务边界优先晾衣，覆盖手动排列和到家优先任务设置，但不切走正在计时或暂停的任务。页面前台到点更新推荐，返回页面也按时间戳恢复；不依赖后台通知。只有其他可先做的家务都完成后才提示等待，缺少时间时提示补充洗衣时间。刷牙和准备衣服仍遵守家务后的顺序。

`npm run test:laundry` 验证普通与受限预览的洗衣完整流程：等待时其他任务可开始、到点自动优先晾衣、当前计时与刷新恢复不受影响、手动确认洗好、晾衣后继续剩余任务及缺少机器时间仍能做其他事。逻辑测试覆盖相同规则和排程边界。
